# SKU补货量计算 Skill
基于京东零售供应链补货场景，背靠供应链Agent制作补货Skill：
将供应链补货决策封装为符合 **Agent Skills 开放标准**的可复用能力：
自然语言触发 → 确定性计算 → 异常拦截转人工 → 自动生成采购建单。

## 核心功能

- **智能计算** - 基于销量数据和库存状态，自动计算最优补货量
- **场景适配** - 自动识别大促、雨天等特殊场景，调整计算策略
- **产能约束** - 接入供应商产能回告，补货量按可供货上限自动封顶
- **风险预警** - 大额订单、长库龄等异常场景自动拦截并转人工审核
- **自动建单** - 补货结果自动填充采购建单模板，一键创建采购订单

## 核心公式

```
补货量 = 目标周转天数 × 日均销量 - 可订购库存
日均销量 = (28日销量 ÷ 28 × 权重) + (7日销量 ÷ 7 × 权重)
可订购库存 = 现货库存 + 在途库存
```

## 特殊场景

| 场景 | 触发条件 | 自动调整 |
|------|---------|---------|
| 大促备货 | 5月30日/10月30日前45天 | 目标周转 35天 → 45天 |
| 雨天 | 过去7天有雨 | 7日权重降为0，改用14日销量 |
| 产能受限 | 补货量 > 供应商回告上限 | 按产能封顶，标记人工审核 |
| 大额订单 | 补货金额 > 100万 | 拦截转人工 |
| 长库龄 | 库龄 > 90天 | 拦截转人工 |
| 零销量 | 日均销量 = 0 | 拦截转人工 |

## 技术特点

- **依赖分层** - 补货计算逻辑仅用 Python 标准库，pandas 只在读写表格时按需导入
- **渐进式披露** - 启动仅加载约 100 token 的元数据，正文与脚本按需读取
- **参数外置** - 9 个业务参数独立成 JSON，支持「配置目录 → 单文件 → 运行时覆盖」三级优先级
- **异常不猜测** - 信息不完整的 SKU 一律排除在自动建单之外，交还人工判断
